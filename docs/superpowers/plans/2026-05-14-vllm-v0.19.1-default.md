## Notes

- **Backward Compatibility:** All existing experiments without `observability` field will automatically use v0.19.1 on next generation. No changes to experiments.json needed.

- **Observability Independence:** Observability deployments (`observability: true`) continue using `ghcr.io/inference-sim/vllm:0.6.8` and are unaffected by this change.

- **Testing on Cluster:** Task 2 validates that the generate script works correctly. Actual cluster deployment testing (spec section "Deployment Testing") is optional and depends on cluster access. If needed, deploy a generated experiment and verify the vLLM pod uses v0.19.1.

- **Version Availability:** The plan assumes `vllm/vllm-openai:v0.19.1` exists on Docker Hub. If deployment fails due to image not found, verify the image exists: `docker pull vllm/vllm-openai:v0.19.1`
